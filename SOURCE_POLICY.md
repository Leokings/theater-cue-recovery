# Source Policy

## Authoritative evidence

The only semantic evidence is public text stored by this contract:

- immutable rehearsal ID and scope;
- the manager-registered cue descriptions and contract-derived order; and
- the authorized reporter's immutable incident report.

The reporter-policy snapshot, cue-sheet digest, configuration digest, sender-bound reference digest, report digest, submission digest, and request digest bind that evidence to a particular deployment and record.

## Explicitly non-authoritative

The contract does not browse the web or consume hidden databases, files, sensors, images, audio, identity registries, stage-control systems, or private workspace data. A wallet address does not establish a person's identity. The manager's configuration and reporter's statement do not prove that a physical event occurred.

## Model handling

All scope, cue, report, and candidate values are untrusted quoted data, never model instructions. Prompts repeat this boundary after the data. The leader and validators may emit only closed JSON schemas; contract code rejects everything else and derives all operational fields deterministically.

## Privacy

Every accepted value is public and permanent. Submit fictional or intentionally public rehearsal material only. Never submit private scripts, secrets, credentials, personal data, health or safety details, or confidential workplace information.
